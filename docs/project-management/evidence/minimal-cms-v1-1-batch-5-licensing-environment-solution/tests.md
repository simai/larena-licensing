# Batch 5 wave A — tests

| Test | What it proves |
| --- | --- |
| `ScopeEntitlementResolverTest` | **The free path never reads a snapshot**, proven with a source that throws if consulted; a site snapshot resolving with no operator level; a locked decision naming a remediation; every inactive status and an expired snapshot locking; `verify_operator` distinguishing "no operator level" from "operator level broken"; a snapshot that is not operator level not being treated as the overlay; and an explain payload carrying no key id, signature or the words themselves |
| `OperatorOverlayNarrowingTest` | A capability only the organization claims is refused **naming the overlay**; a capability only the operator holds is refused naming the scope; the node limit narrowing to the minimum from either side; scopes narrowing independently; a scope with no snapshot inheriting the overlay; an overlay with no scope snapshot applying everywhere; and an undeclared limit being one node rather than unlimited |
| `NodeAdmissionTest` | The happy path; no snapshot refused; three inactive statuses and an expired snapshot refused; a remote-operations-only snapshot refused for lacking the cluster capability; a foreign and an unbound environment refused; an empty node id or fingerprint refused; the limit enforced and **named only when it is the reason**; every other refusal asserted to leak no count; and an undeclared limit admitting exactly one node |
| `DistributedCapabilityDeclarationTest` | The mapping rule producing both frozen ids, including for a hyphenated package so it stays a rule; the enum and the registry agreeing; and **a cross-check against the real `specs/capabilities/registry.json`** asserting both entries exist with the frozen tier, package and kind, and that each entry names its runtime key in its scope text |
| `ScopeEntitlementFailsClosedTest` | Both distributed capabilities locked with nothing behind them and claiming no tier; a source returning a non-snapshot treated as absent; four malformed snapshots refused at construction; the free path still free when every source is broken; and admission refusing every incomplete case without throwing — a security decision that throws is one somebody catches |
